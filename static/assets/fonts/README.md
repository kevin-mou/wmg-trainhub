# 本地字体

控制台离线可用，字体随静态资源分发：

- `instrument-sans-latin.woff2` / `instrument-sans-latin-ext.woff2` — Instrument Sans，界面正文与标题
- `jetbrains-mono-latin.woff2` — JetBrains Mono，日志、ID 与代码

两款字体均来自 Google Fonts，采用 SIL Open Font License 1.1：
https://openfontlicense.org/

中文字符回落到系统字体（PingFang SC / Noto Sans CJK 等）。
